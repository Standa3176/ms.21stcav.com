# Phase 12.1 Plan 01: Paid-only deal creation and cutover guards Summary

Deals are created only by the first paid-status (processing / on-hold / completed / ywraq-new / ywraq-pending) order webhook; unpaid unmapped orders make zero Bitrix calls; per-order lock, create-floor, SHADOW- hygiene and a webhook-source allowlist make the cutover safe.
